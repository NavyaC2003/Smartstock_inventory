# 🚀 SmartStock Inventory Optimization System
> "Transforming traditional inventory management into a smart, efficient, and data-driven system."

---------------------------
## 📌 Project Overview

SmartStock is a web-based inventory management system designed for retail stores to streamline stock handling, automate alerts, and improve decision-making.

It replaces manual inventory tracking with a real-time, automated, and user-friendly solution, making it suitable for both small and large retail businesses.

--------------------------------------
## 🎯 Key Features

- 📦 Real-time inventory tracking  
- 🔔 Automated low-stock alerts  
- 👤 Role-based access (Admin & Staff)  
- 📊 Sales and transaction management  
- 📈 Reports and analytics generation  
- 💱 Multi-currency support  
- ✉️ User-specific email notifications  
- 🔐 Secure authentication using JWT  
- 🧾 Complete transaction history tracking  
- 🤖 Smart assistant for basic queries

  -----------------------------------
## 🏗️ System Architecture

The SmartStock system follows a structured flow from frontend to backend and database, ensuring efficient inventory management and real-time alerts.

### 🔄 Architecture Flow

Frontend → Backend → Database → Alerts System

---

### ⚙️ Components

- 💻 **Frontend (React)**  
  Provides an interactive and user-friendly interface for users.

- 🔧 **Backend (Flask APIs)**  
  Handles business logic, request processing, and authentication.

- 🗄️ **Database (MongoDB)**  
  Stores inventory data, user details, and transaction history.

- 📧 **Alerts System (SMTP)**  
  Sends email notifications for low stock and important updates.

## 💡 Key Innovations

- ✉️ **User-specific email alerts**  
  Only the active/logged-in user receives relevant notifications.

- 💱 **Multi-currency dynamic switching**  
  Allows seamless switching between currencies for global usability.

- 👥 **Role-based dual interface (Admin & Staff)**  
  Separate dashboards and functionalities based on user roles.

- 🔔 **Threshold-based smart alert system**  
  Automatically triggers alerts when stock reaches predefined limits.

- 🎯 **Simple UI for non-technical users**  
  Easy-to-use interface designed for better accessibility and usability.
